# Set genes of a BLASE Data object.

Set genes of a BLASE Data object.

## Usage

``` r
bins(x) <- value

# S4 method for class 'BlaseData'
bins(x) <- value
```

## Arguments

- x:

  a
  [BlaseData](https://andrewmccluskey-uog.github.io/blase/reference/BlaseData-class.md)
  object

- value:

  Vector of integers The new value for bins slot

## Value

Nothing
