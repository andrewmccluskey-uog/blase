# Zhang 2021 Plasmodium falciparum heat shock bulk data

Data originally from <https://doi.org/10.1038/s41467-021-24814-1>. Used
as generated in the BLASE reproducibility documents available at
<https://zenodo.org/records/16615703>, however genes have been subset to
reduce file size.

## Usage

``` r
zhang_2021_heat_shock_bulk
```

## Format

An object of class `data.frame` with 990 rows and 12 columns.
